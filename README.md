# CT小舖 V106

本版在 V105 基礎上新增「無限制開單」店長設定。

## 新增指令
- `/開啟無限制開單`：僅店長／管理員可用。開啟後，同一位客人可以同時建立多張未結單工單。
- `/關閉無限制開單`：恢復原本限制，每位客人只能保留一張未結單工單。
- `/無限制開單狀態`：查看目前設定。

## 行為
- 無限制開單只會跳過「已有未結單工單」的重複限制。
- 快速連點造成的同時重複建立仍由開單鎖保護，不會因為開啟無限制而失去這層保護。
- 購買流程面板不修改。
- `/改名工單` 不修改。
